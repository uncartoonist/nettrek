## Goal

Begin F-004: fix the difficulty curve. First target — the main cannon DPS
cliff.

## Context

Balance had been tuned reactively (HP bumps, player-power HP scaling,
off-screen invulnerability). A holistic audit was needed.

## Changes Made — iteration 1

Audited effective main-gun DPS per level. Found a 3.1x cliff at L3→L4:
damage, shot count, and fire rate all scaled together and multiplied.

- Damage curve `1+floor(lvl/2)` = [1,2,2,3,3] → flat lookup [2,3,4,5,6].
- L4 shot count 5 → 4 (the 5th shot was part of the cliff).
- `getFireRate` floor 3 → 5: L4/L5 intervals [4,3] → [5,5], so fire rate
  stops being a third DPS multiplier at the top.

Result: L3→L4 DPS jump 3.1x → ~1.7x; L1 DPS roughly doubles (fixes the
fresh-ship-vs-cruiser slog).

## Decisions Made

- Smooth the player DPS curve first, then re-tune enemy HP scaling against
  it — one variable at a time so playtest feedback is attributable.

## Open Questions

- Playtest pending: does L1-L3 now feel rewarding, does L4/L5 still faceroll?
- Iteration 2: enemy HP scaling + per-stage difficulty curve verification,
  pending playtest of iteration 1.
